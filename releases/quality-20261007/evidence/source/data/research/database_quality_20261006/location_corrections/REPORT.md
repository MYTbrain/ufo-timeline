## Consumption and unresolved work

`accepted_location_decisions.jsonl` is the sole accepted apply-sidecar. Each record contains event ID, stable decision ID, exact source/date/location/coordinate/precision guards, changed fields, before values, citations and compressed detail hash. `decision_manifest.json` pins the base and outputs. Any stale guard must reject that decision. The 2,460 unaccepted audit candidates remain in `unresolved_location_worklist.jsonl`; the broader 13,090 centroid screen is not blanket-corrected.
