# Workspace and Analysis release — 8 October 2026

This release includes the accepted usability, Analysis data and comparison work
since the validated release source `9f60d3b`. It preserves all 702,893 source
representations, their IDs and row ordering, and the 582,877 mapped records.
The original interactive legend and collapsible map controls remain available.

The hosted candidate is [48969877.ufo-timeline.pages.dev](https://48969877.ufo-timeline.pages.dev/).
Its exact asset verification passed for 261 publicly retrievable objects: 174
Pages objects and all 87 new R2 objects. The frozen Pages inventory also includes
`_headers` and `.nojekyll`, for 176 files. Production promotion and its final
receipt are recorded separately below when completed; hosted candidate validation
does not by itself establish final production publication.

## Accepted improvements

- Compact map-first workspace, side filters on desktop, useful mobile filter
  disclosure, clearer map tools, preserved legend, and native chronology controls
  grouped into a more usable layout.
- Analysis topic rail, focused chart groups, All charts, phone topic/view controls,
  full shared filters, supporting-chart navigation and reliable return to Map.
- Repaired descriptive coverage, delayed chart rendering, scheduling, cache races,
  unknown date handling, partial-date overlap and exports using their result's
  recorded dates and filters. Source independence and strict inferential gates
  remain enforced.
- Additional explicit clock, duration and witness-field recovery; 3,898 guarded
  MUFON month/year intervals; two source-reviewed year corrections; restored crop
  classifications/origins; and seven animal cases with reviewed public evidence.
- Lunar phase/calendar, independent nuclear chronology and facility, and direct
  crop/animal comparisons, with source-date roles, calendar opportunities,
  exclusions and coverage limits visible.
- Planetary positions, aspects and motion; named zodiac conventions; a reusable
  physical ephemeris atlas; scoped cached report aggregation; and three heatmap
  overviews covering nine bodies and 36 unique pairs. Cell details retain calendar
  comparisons, sampled uncertainty and the detailed comparison view.

The accepted UI assets match the retained review sources byte for byte. The
release adds no houses or inferred UTC clocks, no new causal/significance claims,
and no silent source-record merges. Reported positions and dates remain distinct
from measured craft positions, trajectories and verified occurrence timestamps.
Earlier handoffs stating that this work was local-only describe its historical
review stage. This release handoff supersedes those delivery-status statements;
their method, evidence and uncertainty records remain applicable.
