# Additive nuclear context review

This local candidate adds six declared DPRK nuclear-test dates and one reviewed Sandia institution marker. The base FOA/SIPRI chronology remains byte unchanged. `source-runtime.json` contains exact source and artifact hashes, bounded-query identities, and the retained-marker join.

[CTBTO's detection history](https://www.ctbto.org/our-work/detecting-nuclear-tests) identifies the six dates: 9 October 2006, 25 May 2009, 12 February 2013, 6 January 2016, 9 September 2016, and 3 September 2017. Each bounded USGS query returns exactly one record classified as a nuclear explosion. The artifact retains that event's ID, preferred seismic origin time, location, magnitude, and source capture. The [USGS GeoJSON definition](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php) supplies field conventions.

USGS locations are seismic estimates, not verified explosive-device placements. Positional uncertainty and nuclear yield remain null. Magnitude is not converted to yield; deployment category is not inferred. These six events improve later chronology coverage without establishing a complete worldwide post-1998 catalog. Dates after 2017, other missing events, and absent inventory entries do not imply no tests occurred.

[Sandia's official history](https://www.sandia.gov/about/history/) describes its origin in 1945 as Z Division and its work on nonnuclear components of nuclear weapons. The existing Albuquerque/Sandia Base lineage marker is retained by exact ID and coordinates, without creating a new site. Institution-history years are not daily operations; 2026 is the source horizon, not a shutdown year. Year-boundary uncertainty remains one year, and strict spatial eligibility remains false. This expands a partial institution inventory; it does not add power reactors or certify broader military/research markers as nonnuclear controls.

Rebuild: `py -3 scripts/build_nuclear_extension.py --shared-root <protected canonical root>`. Add `--fetch-missing-sources` only when a listed capture is absent. Existing captures are not refreshed or replaced. `tests/test_analysis_nuclear_extension.mjs` verifies source joins, hashes, null unknowns, original chronology preservation, native day/marker comparisons, and institution-boundary gates.

Storage: the canonical additive runtime is `data/analysis_comparisons/nuclear_extension_v1.json.gz`; its small decoded companion supports review. Source captures and this receipt are unique provenance and should be retained. The current deployment and its existing rollback remain in place. No corpus, database, bundle, or release was copied; no new file exceeds 100 MiB, no superseded staging directory was created, and no cleanup is needed. Total growth for sources, runtime, builder, tests, and review is below 0.4 MiB before Git objects.
